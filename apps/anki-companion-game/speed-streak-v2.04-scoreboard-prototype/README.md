# Speed Streak 2.04 scoreboard prototype

This is a standalone Tkinter layout lab. It does not import, install, or modify the Speed Streak add-on.

Run it with:

```powershell
python .\scoreboard_prototype.py
```

The preview uses the current external-window default size of 340 × 700 pixels. Use the controls to compare:

- compact target strip plus a temporary ladder;
- an always-visible ladder;
- a best-only badge;
- recent-five versus best-five comparison sets;
- ranked versus chronological row order;
- live climbing, run completion, pause/restore metadata, deletion, and reset behavior.

The recommended starting point is **Compact target + popover**, **Five most recent completed runs**, and **Ranked**.
