“Thy word is a lamp unto my feet, and a light unto my path.” — Psalm 119:105

Teacher flow
  1. Start a fresh random set and let both children hunt hearts with the small light.
  2. After they have played for a little while, ask: “Would this be easier if you could see more of the path?” Then read Psalm 119:105.
  3. Use Turn on the Lord's light (or press Space). Both players' visibility expands smoothly. The maze and hearts do not move.
  4. Let them continue collecting the same hearts. Point out how much easier it is to find good things and avoid falling when they can see the path clearly.
  5. Use New random set (or R) for a completely new maze and new heart locations.
