“Thy word is a lamp unto my feet, and a light unto my path.” — Psalm 119:105

Teacher flow
  1. Start a new set and let both children hunt hearts with the tiny light.
  2. Ask whether it would be easier if they could see more. Read Psalm 119:105.
  3. Use Turn on the Lord's light (or Space). The maze and hearts stay exactly where they were.
  4. Point out that light helps them see good things and avoid stepping off the path.
  5. Use New random set (or R) for a new maze and heart layout.
