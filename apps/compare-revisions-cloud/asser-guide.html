01 / Prepare the list
1

Choose the resident & dates

In PowerScribe

Set Radiologist to the First Call Resident. Choose a custom time frame, then select Browse.

Use these dates when preparing the review the morning after the overnight shift.
2

Find the overnight case range

Sort by Date modified, then by Attending. Find the relevant attending’s cases modified during the previous night shift and note their first and last case numbers.

Date modified→Attending→Overnight range · e.g. 3–9
Keep this worklist order unchanged through extraction and screenshots. The first case does not have to be case 1.
02 / Extract reports
3

Enter the range, select the first case, Go

PowerScribe Report Exporter

Enter the range in the extractor. Click that first case in PowerScribe, then click Go in the extractor.

Hands off while it runs. Avoid mouse and keyboard use until extraction finishes.
If extraction pauses or stops

Read the message in the exporter and follow its troubleshooting instructions. If you’re unsure or it keeps stopping, contact Sterling before continuing.

4

Paste the reports before taking screenshots

In Compare Revisions

When extraction finishes, Edge should open. Click Paste to insert the report text copied by the extractor.

Text first, screenshots second. Taking a screenshot replaces the clipboard contents. Make sure the reports are pasted before using the snipping tool.
If the browser doesn’t open or the clipboard changed

Open Compare Revisions using the link in this guide. If needed, copy the extraction again from the exporter’s copied-text section or its saved comparison text, then paste it into the report input.

03 / Build the review
5

Add screenshots of case numbers & accessions

In the same PowerScribe worklist, capture the case-number and accession-number columns. Keep both numbers readable and on the same row.

Win+Shift+S

Click Paste screenshot in Compare Revisions. If more rows remain, scroll the worklist, take the next screenshot, and paste it using the next screenshot button. Repeat until the entire range is covered.

Helpful screenshot tips
  • Capture complete digits; avoid cutting off the left edge of case numbers.
  • Use a few overlapping rows between screenshots to avoid gaps. The lookup handles repeated coverage.
  • Keep the same resident, filters and sort order throughout.
6

Finish OCR, then analyze the reports

Wait for all screenshot OCR to finish. If Review OCR shows items to check, use it to compare flagged numbers with their source images and correct obvious errors.

OCR finished→Analyze reports→Wait for 100%
About OCR checks and title modes
  • No individual approval of every row is required. If you choose to proceed with unresolved lookup rows, the analyzer uses the best available lookup information; unresolved accessions may still need correction.
  • The HTML supports Attending and Resident title views. Switching the title mode does not require another analysis or a separate extraction.
  • If analysis reports a problem, inspect it or contact Sterling before sending the file.
04 / Download & send
7

Download the HTML & send it to Sterling

Click Download review HTML. As a quick check, open the downloaded file and confirm the expected cases are there. Attach the HTML file itself to your email to Sterling.
