PowerScribe Report Exporter v0.12

Run PowerScribeReportExporter.exe. No installer, PowerShell, Python, or
AutoHotkey is required on the workstation.

If v0.11 stopped with "Could not remember a separate worklist control":

1. Close the old exporter and any open Compare Report Revisions window.
2. Open this v0.12 exporter and click Remember worklist (F8).
3. Click the FIRST CASE ROW in PowerScribe. Press F8 while PowerScribe is active.
4. Confirm the exporter says Worklist remembered. Return to it and export a
   short range. Check the exported cases and their order before a larger run.

The remembered worklist lasts only for this exporter session. Remember it again
after restarting PowerScribe or changing its layout. It is a keyboard-focus
capture, not an accessibility-pattern capture or a screenshot.

If F8 capture is rejected, the status gives the specific Windows focus reason.
Do not repeat the old setup steps indefinitely. Capture that message or the
Worklist focus lines in the export's .progress.log for troubleshooting.
No usable separate child control means this build still cannot navigate that
custom grid automatically. UAB behavior still requires a workstation trial.

Existing report-click coordinates, timing settings, and report export choices
are retained. No report click needs to be recaptured solely for this update.
Never run the old Review Reports AHK at the same time as this exporter.

See README.md for full instructions and limits.
