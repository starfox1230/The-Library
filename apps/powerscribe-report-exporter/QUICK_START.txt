PowerScribe Report Exporter v0.13

Extract the ZIP and run PowerScribeReportExporter.exe. No installer,
PowerShell, Python, or AutoHotkey is required on the workstation.
Close the old exporter / Review Reports AHK before using this version.

EVERYDAY USE

1. Close any Compare Report Revisions window. Click the first case row
   you want to export in PowerScribe's worklist.
2. In the exporter, enter First case and Last case, then press Go.
   These numbers label consecutive exported cases and set the count;
   they do not select numbered rows in PowerScribe.
3. On success, the comparison text is copied and the website opens.
   Choose Paste, then Analyze reports. Ctrl+V in the report box also works.

Automatic speed starts fast on every run. It adds input settling when a
copy needs retrying; readiness checks finish as soon as they succeed.
There is no filename prompt. Each run gets a new file in Documents\Report
comparisons by default. Options lets you change that folder or speed.
Open comparison file and Open save folder appear after the run.
Notepad opens only if you enable that option.

STOPPING OR TROUBLESHOOTING

Use Stop, Numpad *, or Ctrl+Shift+F12 (the available shortcut is shown
when running). Completed captures are kept if a run stops.

Details shows what was saved, where it stopped, the error, and what to
try next. The same information is saved as a .run-summary.txt file.
Prepare remaining cases sets the remaining range in this launcher only.
You must close the comparison and select the matching starting row in
PowerScribe yourself, then Go. Resumed results are saved in a new file.
Check earlier saved results before deciding which row to resume from.

IF WORKLIST FOCUS CANNOT BE REMEMBERED

1. Expand Options and click Remember worklist (F8).
2. Click the first case row in PowerScribe. Press F8 while PowerScribe
   is active, then return to the exporter.
3. Confirm Worklist remembered, then Go.

This worklist capture lasts for this exporter session. Remember it again
when PowerScribe restarts or its layout changes. If F8 is rejected,
Details / the status message explains the Windows focus problem.

IF THE REPORT CLICK LANDS IN THE WRONG PLACE

In Options, choose Capture report click (optional). With the comparison
open, point inside the attending report body and press F8. Close the
comparison and select your starting worklist row before exporting.
Your existing saved report-click coordinates are retained on upgrade.

Only complete pairs enter the .for-comparison.txt file used by the
website. Pending/unavailable entries remain in the original capture;
Details lists their source numbers. The extractor never uploads reports.

Start with a short range and check report contents and order locally.
Automated checks use synthetic reports, not the UAB workstation.
See README.md for technical details and limits.
