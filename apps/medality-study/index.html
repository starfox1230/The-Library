How to capture and copy
  1. Extract the extension ZIP. At chrome://extensions, enable Developer mode and load the folder containing manifest.json. If updating, replace the files in your existing extension folder and click its Reload button.
  2. Refresh Medality. Open a lesson’s Transcript panel. Use Copy transcript or Save transcript beside its title. The copy shortcut is Ctrl+Shift+Y (Command+Shift+Y on Mac).
  3. Refresh this workspace after updating the extension, then click Import extension captures. You can also export a JSON file from the extension popup and import it here.
  4. Select any combination of lessons, check the preview, and copy. Use Select none to start over. Selections across filters remain selected.

Full transcripts are captured only when you choose Save on an accessible lesson. Missing transcripts are labeled. Automatic captions can misrecognize medical terminology; review against the video and current references.
