ONE-TIME SETUP

Add it to Chrome

  1. Download the extension ZIP and extract it into a permanent folder.
  2. Open chrome://extensions, enable Developer mode, and choose Load unpacked.
  3. Select the extracted folder containing manifest.json. Refresh your open RadPrimer question.
  4. Use Save case, Save + Anki, and My cases in the new panel below the question header. The extension icon also opens your library.

To update later: back up first, replace files in the same folder, click Reload on the extension, then refresh RadPrimer. Keeping the same folder keeps the extension identity and stored library.

A workflow that stays light

Keep doing practice questions. When a case is useful, save it. Choose Save + Anki only when it contains something you consider essential. A note like “I want a card about this differentiating feature” is enough to preserve your intent.

Three knowledge tiers

Occasional review is the default. Must remember marks essential material. Reference only keeps a useful case without placing it in your review queue. Anki status is separate, so you control exactly which cases are waiting for card creation.

Give your agent a focused packet

Open your library’s Anki queue, check the notes and selected facts, and choose Export Anki queue. Give the downloaded JSON file to your agent and ask it to make cards from the selected facts using your repository’s canonical Anki workflow. The packet includes the saved images and their keys. After creation, mark those cases Cards created. Exporting alone does not complete the queue.

Keep a backup

Back up library downloads all cases, images, notes and review dates. Import it on another device using the backup viewer or another installation. This is manual transfer; the extension and web viewer have separate storage. Existing personal edits are preserved on import.

Only the current case is saved when you ask. The extension runs on app.radprimer.com and uses authenticated, same-origin image downloads. It does not collect credentials, crawl the question bank, or upload cases. An unanswered save remains question-only; save again after answering to add explanations and keys. The source assessment link may require jumping to the saved question number. Export a backup before uninstalling, which removes the extension’s storage.
