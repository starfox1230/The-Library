# RadPrimer Case Library

Setup: https://starfox1230.github.io/The-Library/apps/radprimer-study/

A Manifest V3 Chrome extension and private, offline case library. The extension adds **Save case**, **Save + Anki**, **My cases**, notes and selected-fact capture below the assessment question header. Click its toolbar icon to open `chrome-extension://<installation-id>/library.html`.

## Study workflow

- Practice RadPrimer normally. Save a useful case with all its images; default to occasional review.
- Use **Save + Anki** for essential facts. Add a precise note or highlight now or in the library.
- In the library, images appear first in one large viewer. Switch groups using tabs, or use **Compare groups** to view two groups side by side. On desktop, two groups containing one image each automatically open together. Use **Focus images** for more room (Escape exits); click an image to enlarge it.
- The question, answer explanations and notes use separate tabs in a side panel. Revealing the answer unlocks annotations and image keys. Image keys stay collapsed until needed. Thumbnails and left/right arrows navigate within a group, retaining your selected image when you change tabs. A single case uses the full width; multiple cases have a collapsible case list.
- Choose reference only, occasional review or must remember. Reference cases stay out of the revisit queue. Schedule another visit tomorrow, in a week or in a month; these are explicit review dates, not an adaptive spaced-repetition algorithm. No reminders run in the background.
- Export the **Anki queue** as a self-contained JSON source packet with media. Give it to an agent following `AGENTS.md`, `CARD_STYLE_GUIDE.md` and `APKG_PACKAGING.md`. No cards or APKGs are generated by this app. Export does not remove the queue; mark **Cards created** after the actual card workflow completes.
- Archive and restore cases without deleting them.

## Install / update

Extract `downloads/radprimer-case-library.zip` to a permanent folder. At `chrome://extensions`, enable Developer mode, click Load unpacked, and select the folder containing `manifest.json`. Refresh RadPrimer. Browser extension installation must be completed/approved by the user.

For updates, back up the library, replace files **in the existing installation folder**, click Reload, and refresh RadPrimer. Removing and reinstalling the extension can remove saved data. No Anki add-on is installed or modified.

## Capture contract and limits

The adapter was derived from a logged-in `app.radprimer.com/assessment/<id>` page on October 21, 2026, including two image groups with four images each. It reads the rendered DOM, not private application objects or undocumented assessment APIs. The question was answered during authorized inspection to verify explanations, teaching point and image-key markup.

- Captures only the currently open question on explicit save. Never answers, advances or flags a question on RadPrimer. It visits the current question's image groups/thumbnails and restores the prior selection. Capturing may take several seconds; avoid navigation until it finishes. Navigation to a different question aborts capture.
- Uses `#mcq-question-stem`, `.mcq-answer[data-answer-id]`, `.answer-js`, `.mcq-answer-justification`, `.teaching-point-js`, `.image-group[data-image-group-id]`, `.image-slider-button`, `.image-large-js`, and `.image-caption-js`.
- Explanations/correctness/keys are captured only after RadPrimer reveals the answer. Before answering, a question-only save contains original images and choices. Save again after answering to enrich it. Re-saving a question-only view cannot downgrade an existing revealed answer or discard user notes.
- Visits every thumbnail to associate the displayed key with its exact image, preserving group and image IDs/order. Arrow glyph images in keys become explicit labels such as `[White solid arrow]`. Original and annotation image variants are downloaded as authenticated same-origin image bytes, using the observed `style=xlarge` / `annotated=true` image URL convention. Each fetch is limited to 20 seconds and 25 MB, validates MIME type, and stores a local data URL. Failed downloads remain visible and can be retried by saving again.
- IDs use SHA-256 over question stem and sorted answer IDs, avoiding collisions between assessments or question numbers. The same question in another assessment updates one saved case. Source assessment links do not guarantee a deep link to an individual question; use the recorded question number.
- Unsupported layouts report an error; capture completeness is based on recognized DOM groups. Future RadPrimer markup or image delivery changes may require adapting the selectors. Full installed-extension verification requires the user's installation/reload; unit/browser fixture tests cannot establish authenticated image download behavior in an installed extension.

## Storage and privacy

Cases and embedded image files live in extension-origin IndexedDB with `unlimitedStorage`. Content scripts send captures to the extension worker; storage is not shared with RadPrimer. The manifest grants no broad host access, tabs permission, cloud connection, external messaging or web-accessible resources. The worker accepts only own-extension messages from the exact RadPrimer origin. Extension pages use a restrictive CSP: no remote scripts, remote images or network connections. Captured text is rendered through text nodes; imported media allows only PNG/JPEG/WebP/GIF data URLs. No credentials, licensed case content, notes or images belong in Git.

The hosted **backup viewer** shares the same UI but uses separate browser-origin IndexedDB. It receives no extension data automatically. Import a backup explicitly to review cases there or on a phone. The public setup page contains only original interface art and instructions. No licensed case content is bundled. Use for personal study within your existing access.

Export backups regularly and before uninstalling. Backups include notes and original/annotated image data. Import validates every record before an atomic merge and preserves existing personal edits. Existing nonempty notes win; selected facts are combined. New case source content and missing media can be enriched. A backup is not encrypted. Import limit is 250 MB per file. Storage/device failures remain possible; no cloud sync or automatic backup is claimed.

## Development

Buildless HTML/CSS/JavaScript, published through the repository's GitHub Pages workflow. This is an extension within the existing repository, not a separately hosted Sites project or a temporary quiz app.

```powershell
cd apps/radprimer-study
npm ci
npm test
npm run package
```

Tests use synthetic content, mock Chrome APIs, jsdom and fake IndexedDB. Runtime files are explicitly allowlisted in the ZIP packager. Never package fixtures, personal backups, browser profiles or `node_modules`. Run the package command again after every runtime edit.

For visual QA, serve this folder locally and open `tests/preview.html`. It creates original canvas-generated images and one or two synthetic cases on that local origin; it never reads the extension library. The preview files are excluded from the extension ZIP. Check single-group viewing, comparison, focus mode, responsive widths and the question/explanation/notes tabs. Viewer height is measured from the actual viewport and controls so the image navigation stays visible; long desktop text scrolls within its own panel. Images use `object-fit: contain` and are never cropped to fill the viewer.

### v1.0.1: RadPrimer JPEG response labels

Live asset inspection confirmed that both original and annotated image URLs return valid JPEG bytes with the nonstandard `image/jpg` response type. The original loader rejected this alias, and simply accepting it would still fail the library's canonical data-URL validation. The loader now accepts `image/jpg` and normalizes the Blob type to `image/jpeg` without changing its bytes before creating the offline data URL. PNG, standard JPEG, WebP and GIF handling is unchanged; HTML/login responses, SVG, empty and oversized images remain rejected. Save feedback now includes the actual image error when a capture is incomplete.

The 20-test suite now includes the production image loader with `image/jpg` responses through capture, validation and IndexedDB round trip, as well as the supported response types and failure cases. Refreshing RadPrimer alone left Chrome running the previous code during troubleshooting. After the user reloaded the extension and RadPrimer was refreshed, the installed fix successfully re-saved the previously failing case: **2/2 images offline**, with answer explanations and image keys included and no media-error warning. This acknowledgment is sent after the IndexedDB write completes. Re-save other affected cases to fill missing media while preserving notes and review state. The extension-origin library page itself could not be inspected by browser tools because that URL protocol is blocked; its rendering remains covered by the UI tests.
